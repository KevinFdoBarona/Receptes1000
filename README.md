# Receptes1000

Receptes1000 és una aplicació web per guardar, cercar, compartir i valorar receptes de cuina. Està pensada per a famílies i també per a cuiners i empreses de restauració. Volem evitar que les receptes es perdin en paper i donar als restaurants una manera comuna de passar-se els procediments entre treballadors.

Projecte Intermodular 2026-2027 (UT1).

## Què farà (MVP)

1. Gestionar receptes: crear, modificar i eliminar, amb ingredients, passos i visibilitat pública o privada.
2. Cercar receptes per nom o ingredient, entre les nostres i les públiques dels altres usuaris.
3. Valorar receptes públiques i veure'n la valoració global.

Per fer-ho cal tenir usuari, però el registre és només una condició tècnica, no una funcionalitat a part.

## Què no farem

Inventari i comandes, escandall i nutrició, pagaments, app mòbil nativa, xarxa social completa i substituir TPV o ERP.

## Tecnologies

HTML, CSS i JavaScript al front. Java amb Spring Boot al back. MySQL per a les dades. Git i GitHub per al control de versions.
